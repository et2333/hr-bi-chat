# HR智能问数产品设计方案

> 版本：V1.0 ｜ 日期：2026-09-13 ｜ 状态：评审稿

---

## 一、产品定位

**一句话定位**：面向HR部门的AI对话式数据分析助手——让HR用一句话获取人力数据洞察，无需依赖IT取数或手工做表。

**价值主张**：

| 痛点 | 现状 | 产品价值 |
|---|---|---|
| 取数靠IT | 提需求→排期→交付，周期2-5天 | 秒级自助问答 |
| 分析靠Excel | 手工透视、口径不一 | 自动生成可视化+统一指标口径 |
| 决策靠经验 | 人效、流失缺数据支撑 | 自然语言洞察归因 |

**北极星指标**：问数成功率（准确返回正确数据的会话占比）≥ 90%

---

## 二、目标用户与核心场景

### 2.1 用户角色

- **HRBP/HR专员**（高频）：日常查数、做报表
- **HR负责人/HRD**（中频）：人效分析、决策支持
- **CHO/管理层**（低频）：看订阅报表、趋势大盘

### 2.2 Top 5 核心场景

1. **日常查询**：「上月入职了多少人？」「研发中心在职人数是多少？」
2. **复杂条件**：「司龄3年以上、绩效B以上、职级P6-P8的女员工名单」
3. **对比分析**：「对比今年Q1-Q3各部门离职率」「近6个月招聘完成率趋势」
4. **报表生成**：「给我生成一份部门人力成本月报，发我邮箱」
5. **归因洞察**：「为什么销售部离职率升高了？」（辅助归因）

## 四、核心功能模块详设

### 4.1 智能问数（核心模块）

**交互流程**：

```
用户提问 → 意图识别 → 槽位补全(必要时反问澄清) → 权限校验+SQL改写
→ 执行查询 → 结果渲染(表格/图表/数字卡) → 结论摘要生成 → 追问推荐
```

**功能要点**：

- **意图识别**：区分查询类（查数）、分析类（对比/趋势/排名）、操作类（生成报表/订阅）、闲聊兜底
- **澄清反问**：模糊提问主动澄清，如「查一下离职率」→ 反问「您想看近30天还是本年度？按部门还是全公司口径？」
- **多轮对话**：支持上下文继承，「那研发部呢？」「换成按季度看」
- **同义词映射**：「花名册=在职名单」「离职率=turnover rate」「HC=编制」
- **结果呈现三段式**：
  1. 直观结论（数字卡/一句话）
  2. 明细数据（可下钻表格）
  3. 可视化图表（AI推荐图型，可切换）
- **可信可溯**：每次回答展示数据口径、时间范围、数据更新时间，支持「查看SQL」和一键纠错反馈

### 4.2 多维分析与对比

- **维度下钻**：集团 → 公司 → 部门 → 小组；任意维度互换（时间/组织/职级/岗位序列）
- **对比模式**：同比/环比、部门间横向对比、实际vs编制（达成率）
- **归因分析**：指标异动自动拆解贡献度（如离职率↑主要由A部门、1-3年司龄段贡献）

### 4.3 报表中心

- **自定义报表**：问答结果一键存为报表；可视化拖拽字段生成；定时刷新
- **报表订阅**：按日/周/月推送至邮箱/IM（企业微信/钉钉/飞书）
- **模板库**：预置人力月报、编制盘点、离职分析、招聘漏斗、考勤汇总、人力成本等10+标准模板

### 4.4 数据集成

- **接入范围**：HRIS（人事主数据：组织/人员/异动）、考勤系统、薪酬系统、绩效系统、招聘ATS
- **同步机制**：T+1全量 + 关键表（人员异动）准实时增量；同步监控告警
- **数据质量**：入仓校验规则（如入职日期≤在职日期）、质量看板

### 4.5 权限与安全（重点）

**权限模型 = 数据范围 × 字段级脱敏 × 功能权限**

| 权限维度 | 规则示例 |
|---|---|
| 组织范围 | HRBP只能查所辖部门；集团HR可查全量 |
| 字段脱敏 | 薪酬字段仅薪酬岗可见；身份证号/手机号默认脱敏 |
| 行级权限 | 算法在SQL生成时自动注入过滤条件，而非前端过滤 |
| 操作权限 | 导出、看明细、订阅需单独授权；敏感操作留痕审计 |

**安全机制**：

- 问答结果不缓存跨权限复用
- SQL白名单校验（只读、禁止DDL/DML）
- 导出水印
- 全量审计日志

## 五、关键指标体系（预置语义层）

| 域 | 示例指标 |
|---|---|
| 人员 | 在职人数、入职人数、离职人数、离职率、净增员 |
| 组织 | 编制数、缺编率、管理层级、人效（人均营收/利润） |
| 招聘 | 招聘完成率、平均到岗周期、渠道转化率 |
| 考勤 | 出勤率、加班时长、请假分布 |
| 薪酬 | 人力成本、人均薪酬、薪酬带宽渗透率 |
| 绩效 | 绩效分布、绩效-离职交叉分析 |

## 六、非功能需求

- **性能**：简单查询 P95 < 3s；复杂分析 < 10s；并发 100 QPS
- **准确性**：NL2SQL执行准确率 ≥ 90%（上线前用500+标注问句集回归测试）
- **可用性**：99.9%；AI服务降级方案（预设常用问句直接命中缓存SQL）
- **合规**：符合《个人信息保护法》，薪酬/身份信息最小可用原则
