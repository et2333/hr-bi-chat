## 1. 测试概述

### 1.1 测试范围

| 范围 | 内容 |
|---|---|
| 功能测试 | 智能问数/澄清/多轮/可视化/分析/报表/订阅/管理后台（FR-01~23） |
| 权限安全测试 | 行级权限/字段脱敏/功能权限/审计/SQL注入与越权（FR-17~20，BR-01~03/05/06/11~13） |
| AI准确率测试 | NL2SQL执行准确率（标注问句集回归） |
| 性能测试 | P95延迟/并发/容量（PRD 8.1） |
| 异常与降级测试 | 故障场景/降级梯度L0-L3（FR-24） |
| 数据测试 | 首灌核对/同步/质量校验（FR-15/16） |
| 不在范围 | 源系统内部功能、SSO平台自身、IM平台消息通道底层 |

### 1.2 测试账号矩阵（权限覆盖设计）

| 账号 | 角色 | 组织范围 | 特殊权限 | 用途 |

| hr02 | HRBP | 销售部 | 无明细 | 无权限对照 |
| hr03 | HR专员 | 仅职能一级部门 | 导出 | 导出管控 |

| dat01 | 数据管理员 | — | 语义层/数据监控 | 口径治理 |
| test09 | 无权限新用户 | 无授权 | 无 | 越权与空状态 |

### 1.3 测试环境要求

- 环境：staging（生产1:1缩配，脱敏全量结构数据，100万人员规模测试数据集）
- 数据：种子数据（13指标+同义词）已初始化；标注问句集500条已加载
- 混沌工具：预置故障注入脚本（停vLLM/断Kafka/杀Pod）

### 1.4 用例编号规则与优先级

- 编号：`TC-{模块}-{序号}`（模块：CHT问数/CLF澄清/MUL多轮/VIZ可视化/ANA分析/RPT报表/SUB订阅/ADM后台/SEC安全/AUD审计/DAT数据/PRF性能/EXC异常/AI准确率）
- 优先级：P0冒烟必测 / P1核心 / P2一般
- 通过标准：P0用例100%通过、P1≥95%、无严重级以上缺陷遗留（PRD 9.1）

## 17. 缺陷管理与通过标准汇总

### 17.1 缺陷等级定义

| 等级 | 定义 | 示例 |
|---|---|---|
| 致命 | 数据错误/越权/安全漏洞/系统不可用 | 返回越权数据、SQL注入成功、主链路崩溃 |
| 严重 | 核心功能不可用且无替代 | 澄清失效导致错误答案、订阅全量失败 |
| 一般 | 功能异常但有替代路径 | 图型切换不记忆、排序失效 |
| 轻微 | 体验问题 | 文案错别字、样式偏差 |
