# 新表达任务对照 v1

12 条问句在首次模型运行前固定，6 条查数、3 条缺参澄清、3 条不支持问题。运行时保持普通 Java 目录，不插入模拟干扰口径。每题新建会话，repair=off、memory=on、semantic 检索表示固定，仅 off/lexical/hybrid 不同，最多 36 次 Qwen Plus 调用，无自动重跑。

独立性边界：表达由助手编写，与 212 条既有语料/题集问句规范化精确重合为零，未进入 few-shot；业务任务和结果复用已校验的 literal-seed 基准。不是新用户流量，不保证语义无重合，人工题意复核状态待完成。`frozen` 表示版本锁定，不能解释为独立第三方盲测。

六条查询保留显式日期/组织 UI 控件，问句不另外给冲突日期。三条停止类不提供期间、已指定研发中心；必须返回规定状态，不提供业务数字、不执行工具，并具备可见 trace。缺证据算失败，不能凭无答案推断没有查询。拒绝与澄清分开评分。

运行前核对 `cases.json` 中原句及 `expected`。首次运行后保留全部成败，禁止改预期、把失败题放入检索示例后再声称泛化增益。真失败修复需独立版本或回归报告。各臂计所有任务和按场景计分，报告配对修复/退化、真实 Token 和端到端耗时；小样本无增益也保留。
